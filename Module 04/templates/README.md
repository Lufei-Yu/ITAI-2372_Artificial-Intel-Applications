# Templates Folder

## Overview
The `templates` folder contains the HTML files used to display the user interface of the Finance Insights App. Flask uses these templates to show the web page and display the results of financial text analysis.

## Files

### `index.html`
This is the main web page of the application. It allows users to:

- Paste a financial news article or headline.
- Submit text for sentiment analysis.
- Enter an optional question about the article.
- View the predicted sentiment, such as positive, negative, or neutral.
- Read a summary or an answer generated by the application.
- View the cleaned text used for sentiment analysis.

## How It Works
The `app.py` file uses Flask's `render_template()` function to load `index.html`. When a user submits financial text, the application processes the text and sends the results back to the HTML template for display.

The page also uses CSS from the `static` folder to control its appearance and layout.

## Purpose
The templates folder separates the HTML interface from the Python application logic. This makes the project easier to organize, maintain, and improve.
